# AWS ECS Fargate — Python Web App

## Overview
Deployed a Dockerized Python web application using AWS ECS Fargate.

## Technologies
- Python 3.12
- Docker
- Amazon ECR
- AWS ECS Fargate
- AWS CloudShell & CLI
- IAM & Security Groups

## What I Did
1. Built a Docker image.
2. Pushed the image to Amazon ECR.
3. Deployed the application using `deploy.sh`.
4. Configured network security.
5. Verified the ECS task was running and healthy.
6. Successfully tested the application on port 8080.

## Results
- **Deployment:** Successful
- **ECS Task:** Running
- **Health Status:** Healthy
- **Region:** us-east-1
